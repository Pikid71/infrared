Eaglercraft
Eaglercraft is a free, open-source project that allows users to play Minecraft Java Edition directly within a standard web browser without requiring any downloads, installations, or paid accounts. Originally created by an independent developer known as LAX1DUDE, it compiles Mojang’s official game assets into JavaScript and WebAssembly using a tool called TeaVM. This process allows a fully functional version of the game to run smoothly inside a web browser.
Hollow Knight
Hollow Knight is a 2D action-adventure video game developed and published by Team Cherry in February 2017. You play as a small, silent knight exploring a vast, ruined underground kingdom called Hallownest. The game belongs to a genre called "Metroidvania," which means you explore a giant connected map, unlock new movement abilities, and return to areas you could not reach before.

Retro Bowl college
Retro Bowl College is a free-to-play American football game that allows players to manage and coach their own college football team. The game features retro-style graphics and gameplay, reminiscent of classic football video games from the 1980s and 1990s. Players can recruit athletes, develop strategies, and compete in various college football leagues and tournaments.
